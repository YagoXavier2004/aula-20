## 🎯 Objetivo da Atividade

Desenvolver a lógica algorítmica e o controle de fluxo no JavaScript moderno através de **4 atividades práticas de regras de negócio**:

1. **Atividade 1 (Desconto Progressivo):** Utilizar operadores aritméticos e a estrutura condicional encadeada `if / else if / else` para calcular faixas de desconto em um e-commerce e exibir os valores calculados com Template Literals.
2. **Atividade 2 (Validador de Acesso):** Combinar operadores relacionais e lógicos (`&&`, `||`, `!`) com igualdade estrita (`===`) para autenticar o acesso a uma área restrita e comprovar o perigo do `==` em dados de segurança.
3. **Atividade 3 (Rastreamento de Pedido):** Implementar a seleção múltipla com a estrutura `switch / case / break / default` para simular as etapas logísticas de entrega de um produto.
4. **Atividade 4 (Par/Ímpar & Estoque com Ternário):** Utilizar o operador módulo `%` e o Operador Condicional Ternário `? :` para escrever decisões concisas e elegantes de uma única linha.

## 🚀 Como Executar e Testar

1. Abra a pasta `atividade-javascript-operadores-condicionais` no **VS Code**.
2. Abra o arquivo `index.html` com o **Live Server** ou no seu navegador.
3. Abra as Ferramentas de Desenvolvedor pressionando **F12** (ou `Ctrl + Shift + I`) e vá para a aba **Console**.
4. Edite o arquivo `js/script.js` resolvendo os 4 desafios propostos e acompanhe os resultados no Console em tempo real.
