Atividade 19: Operadores, Lógica & Tomada de Decisão

Esta atividade prática contém 4 desafios de regras de negócio reais executados diretamente no Console do navegador.

Como visualizar a execução:

Pressione a tecla F12 no teclado ou o atalho Ctrl + Shift + I e clique na aba Console.

  • 🛒
    Atividade 1: Calculadora de Desconto Progressivo em Carrinho (Operadores Aritméticos e if / else if / else).
  • 🔐
    Atividade 2: Validador de Acesso ao Painel com Igualdade Estrita (===) e Operadores Lógicos (&& e ||).
  • 📦
    Atividade 3: Rastreador de Status de Pedido com Seleção Múltipla (switch / case / break / default).
  • ⚡
    Atividade 4: Verificador de Par/Ímpar com Módulo (%) e Decisão Concisa com o Operador Ternário (? :).
Abra o arquivo js/script.js no seu VS Code para realizar a atividade.
